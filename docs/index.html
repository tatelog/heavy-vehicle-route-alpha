データ出典・判定ロジック

このツールが「何を根拠に通行可否を表示しているか」と、利用している無償の公的・準公的データの出典・方針をまとめた技術メモです。商用の有料交通APIは前提にしていません。

最終確認: 2026-06-02 / ステータス: α版（試作・仮属性を含む）

01判定の考え方

基本は 車両諸元 × 道路属性 の突き合わせです。Google Maps のような完全なライブ渋滞ナビではなく、通行可否の一次検討と現場共有を目的にしています。

候補ルートの評価は、各区間の通行可否を土台に、チーム共有マーカー（現場の最新情報）を加味します。将来は公的な交通量・規制データを「混雑傾向」「注意・不可区間」として重ねます。現場の共有情報は、公的データより優先して表示する方針です。

03入力 — 道路種別

道路は種別で色分けし、各区間に幅員・高さ・重量の属性を持たせて車両諸元と比較します。

種別地図色扱い
重要物流道路オレンジ大型車両の基幹ルート候補
緊急輸送道路ブルー幹線として優先評価
一般道グレー制限を満たす場合に補助的に利用
仮属性についての注意：現在の各区間の幅・高さ・重量は、道路種別ごとに割り当てた試作の仮属性です。実際の標識・規制が優先します。正式な特殊車両の通行可否は、必ず国の「特殊車両通行確認システム」でご確認ください。

04出力 — 通行可否と共有マーカー

車両諸元が区間属性を満たせば 通行可、超過すれば 通行不可 として地図と統計に反映します。

現場の共有マーカー

現場の最新情報を、データより優先して表示します。

種類用途
渋滞混雑区間の注意喚起
通行止め通行不可として強く反映
工事工事規制区間
狭い離合不可・幅員注意

05地図・位置情報

地図タイル

  • 地理院タイル（国土地理院）
  • OpenStreetMap contributors

GPS・位置情報

  • Geolocation API は HTTPS が必要です。GitHub Pages はHTTPS配信のため、スマホから現在地取得・追従が可能です。
  • 位置共有は画面を開いている間のみ動作します。バックグラウンドでは更新されません。
  • 走行距離は GPS 概算です。GPS が使えないセッションは通行実績ログの対象外です（誤データ防止）。
  • 本番方針：現場位置情報・通行ログは外部クラウドに置かず、自社管理の PocketBase へ集約します。

06公的交通データ連携（準備中）

有料の商用交通APIは使わず、無償で利用できる公的・準公的データを優先します。各ソースは利用規約・出典表記・取得頻度・再配布可否を確認してから有効化します。

JARTIC/国土交通省 交通量API 要規約確認

種別: 常時観測交通量 費用: 無料

ルート周辺の観測交通量から混雑傾向を推定し、候補ルートのスコアに反映します。遅延分数そのものではなく「混雑傾向」として扱います。

  • ライブ渋滞所要時間そのものではない
  • 観測点ベースのため全線を直接カバーしない場合がある
  • 観測条件・機器要因で精度が変動する
jartic-open-traffic.org xROAD 常時観測交通量

JARTIC 交通規制情報オープンデータ 要規約確認

種別: 交通規制・通行止め・工事 費用: 無料 / オープンデータ規約

通行止め・規制・工事を候補ルートに重ね、通行不可・注意区間として強く反映します。

  • API ではなくダウンロード形式の場合、定期取得・整形が必要
  • リアルタイム性は公開更新頻度に依存する
jartic.or.jp/service/opendata

国土交通省 道路情報提供システム 調査中

種別: 道路規制・気象・路面 費用: 閲覧無料

道路気象・路面・規制を注意情報として表示する想定。閲覧サイト中心の可能性があり、スクレイピング前提にはしません。

road-info-prvs.mlit.go.jp

有効化までの段取り

  1. 各データソースの利用可否・規約・出典表記・再配布可否を確認する
  2. 規約同意後、設定で交通量・規制データの連携を有効化する
  3. 候補ルートの周辺範囲から観測点・規制情報を取得する
  4. 交通量が大きい区間を「混雑傾向」、規制を「不可・注意区間」として反映する
  5. 現場のチーム共有マーカーは、公的データより優先して表示する

07免責

本ツールは一次検討・現場共有のための補助であり、通行可否を保証するものではありません。表示には試作の仮属性・概算値・更新遅延を含みます。正式な特殊車両の通行可否は、国の「特殊車両通行確認システム」および現地の標識・規制で必ずご確認ください。
